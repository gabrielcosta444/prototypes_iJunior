# Protótipos comerciais

Cada protótipo deste diretório é uma aplicação independente.

| Projeto | Pasta | Descrição |
| --- | --- | --- |
| Fluxo Fiscal | `fluxo-fiscal/` | Gestão e automação documental para a operação Allebras |
| General Green | `general-green-gestao-operacional/` | Gestão de operações em usinas fotovoltaicas |

Entre na pasta do projeto desejado e use `npm run dev` para iniciar sua apresentação.
